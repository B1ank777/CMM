## 实验目的

分析 Ron/Roff 阻值对功耗的定标效应。在 32×32 crossbar 上扫描 3 组 Ron/Roff 组合（固定 on/off ratio = 100×）与 3 个高导态占比（10%/30%/50%），验证读出功耗随 Ron 增大按比例下降，同时确认列电流动态范围仅由 cell state 分布决定、与绝对阻值无关。

## 运行命令

```bash
python experiments/spice/sweep_ron_roff_cell_state.py --n 32 --vread 0.2 --pulse-ns 50
```

## 参数说明

| 参数 | 指定值 | 来源 | 默认值 | 说明 |
|------|--------|------|--------|------|
| --n | 32 | 用户指定 | 16 | crossbar 阵列规模 |
| --vread | 0.2 | 用户指定 | 0.1 | read pulse 电压 (V) |
| --pulse-ns | 50 | 用户指定 | 10.0 | read pulse 宽度 (ns) |
| --seed | 1 | 默认值 | 1 | Ron/Roff 分布随机种子 |

> 扫描维度（脚本内置，非 argparse 参数）：Ron/Roff ∈ {(1k/100k), (5k/500k), (10k/1M)}，high-G 占比 ∈ {10%, 30%, 50%}。

### 功耗定标验证

| 定标关系 | 10% high-G | 30% high-G | 50% high-G |
|----------|-----------|-----------|-----------|
| E(1k) / E(5k) | 5.00× | 5.00× | 5.00× |
| E(1k) / E(10k) | 10.00× | 10.00× | 10.00× |
| E(5k) / E(10k) | 2.00× | 2.00× | 2.00× |

> 能量与 Iread 严格反比于 Ron：Ron 每增大 N×，功率和电流精确下降 N×。定标关系不受 high-G 占比影响。

### 列电流动态范围 vs high-G 占比

| high-G | col_range |
|--------|-----------|
| 10% | 25.75× |
| 30% | 2.88× |
| 50% | 1.57× |

> col_range 仅由 high-G 占比决定，与 Ron/Roff 绝对阻值完全无关（三组阻值在相同 high-G 下 col_range 一致到小数点后两位）。high-G 从 10%→50%，动态范围从 26× 压缩至 1.6×，说明高导态单元增多后列电流趋于均匀。

## 备注

- 三组 Ron/Roff 的 on/off ratio 均固定为 100×，消除比值变化混淆
- 功耗与 Ron 的线性定标关系验证了 I = V/R 的基本欧姆定律在此仿真框架下成立
- 实际器件选型时，Ron 越大越省功耗，但需权衡 read margin（Ron 过小导致绝对电流过大，Ron 过大则受 Roff 漏电影响显著）
- 该实验作为 experiment_b 输出，与 experiment_a 形成对照：a 为固定 on_prob 的 random 单点仿真，b 为 Ron/Roff × high-G 全因子扫描
